面向招聘方的可运行网页演示，包含余念回响、贴贴壁纸、月末拾光与宿舍生活研究看板。

## 直接体验

- 在线：https://dawwnforu.github.io/portfolio-showcase/
- 离线：下载 Release 中的 HTML 原型 ZIP，完整解压后双击 `index.html`。
- 不需要安装 Node.js，不需要运行命令，不需要登录。

本仓库存放可部署的演示文件，不是需要自行构建的开发工程。第三方依赖许可保留在相邻文件中。
