试一试：写一条想法 → 添加话题 → 保存 → 在「回看」中搜索；保存两条后可对照原话。

03

月末拾光

效率工具 / 照片排版

试一试：导入照片 → 修改毫米尺寸和份数 → 查看排版 → 导出打印 PDF。

04

宿舍生活研究

用户研究 / 交互数据看板

从问卷中的作息、噪音与生活习惯，理解共同居住的摩擦。

试一试：查看数据清洗说明 → 切换分析章节 → 悬停图表查看数值。不同分析的样本量以标注为准。

离线体验说明
  1. 下载 ZIP 后，先完整解压，再双击 index.html。请保留文件夹结构。
  2. 推荐使用桌面版 Chrome 或 Edge。核心操作无需联网，也无需安装开发工具。
  3. 可用 示例风景图 和 透明贴纸 体验导入。示例为专门制作的演示素材。
  4. 余念回响的记录仅保存在当前浏览器；壁纸和照片排版请及时导出。建议使用示例内容体验。
  5. 外部项目链接需要联网。看板展示的是项目研究结果，不含原始问卷文件。
